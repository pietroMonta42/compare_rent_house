# Agent Wiki

[← Index](./index.md)

This wiki helps agents navigate the Rent House Radar repository without rereading the whole codebase.

## How to use

1. Read [index.md](./index.md) for quick facts.
2. Open one relevant core page.
3. Search only the mapped source path.
4. If the wiki and code disagree, trust the code and update the wiki when the mismatch is structural.

## Growth

- Keep bootstrap pages short.
- Add a layer or domain page only after a recurring pattern appears.
- Use `update-wiki` for durable navigation knowledge, not ticket notes.
- Add `log.md` only when the wiki grows substantially or has multiple maintainers.
